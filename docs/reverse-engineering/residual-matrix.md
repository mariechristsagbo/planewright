# Residual coverage matrix

This matrix tracks every item of issue #1's included scope (`S-xx`, defined below) and every
entry of the [feature inventory](feature-inventory.md#inventory-ids) (`F-xx`). Every row has a
status, the evidence it rests on, its limitations and the next observation that would close it.
`documentation.test.mjs` in `research/excalidraw/tests/unit` fails if a scope or inventory ID
has no row, a row has an empty cell, or a behaviour entry cites a row for an unobserved undo
dimension that the row does not plan.

Status: ✅ observed with reproducible evidence, within the stated limitations; 🟡 partially
observed; ❌ not observed; ⛔ out of scope or not attempted by policy. "DL/DD/M" is desktop
light / desktop dark / mobile. P is the order in which follow-up work should run (1 first).
The sessions after s7 are the R-76 runs s8–s11 and the observation batch s12–s14 (2026-11-05, on
a later build of the reference); the rows they changed cite them.
